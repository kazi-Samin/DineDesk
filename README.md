# DineDesk

Online Restaurant Ordering & Table Reservation Platform — Next.js 15, TypeScript, Tailwind CSS.

## Overview
DineDesk connects diners with Dhaka's celebrated culinary institutions, independent bistros, and artisanal kitchens. Built with precision based on Google Stitch design architecture.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS with custom design system
- **Icons:** Material Symbols Outlined & Lucide React
- **Data Architecture:** Fully typed mock models ready for backend integration

## Pages Implemented
- `/` — Editorial Landing / Home Page with quick discovery, featured restaurants, top rated showcase, craving categories, testimonials, and partner CTA.
- `/explore` — Comprehensive restaurant exploration with live filters (Open Kitchens, Service Mode, Cuisines, Tasting Tiers, Ratings, Dietary preferences), sorting, grid/list view toggle, and pagination.

## Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
